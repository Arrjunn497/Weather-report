A complete full-stack build.

WeatherNow joins frontend, backend, third-party API, database and deployment into one platform.

Frontend

HTML, CSS, JavaScript and a modern framework for an interactive interface.

Backend

Node.js with Express.js handles API requests and business logic.

Weather API

Real-time data from a reliable provider, stored or cached as needed.

Database

MongoDB or MySQL keeps user preferences and search history.

Browser→Express API→Weather API→Cache and database→Your forecast

Built in Visual Studio Code, versioned with Git and hosted on GitHub. Authentication is added where needed.
